# Ambassador 原始素材

## 目录
- 来源
- 分区

## 来源
来自用户提供的 Figma `college ambassador program` 区域。下载保存为 SVG，保留原始字节、颜色、viewBox 与图层内容；不使用设计截图作为页面图片。没有保留临时下载地址。

## 分区
- `hero/`：标题各图层、四周云朵、独立眼睛。
- `program/`：封面、展开文件夹左右原图、回形针。
- `perks/`：背景、地面、人物各图层、三个图标与图钉、公告星号。

人物黄色角色由原 Figma 独立图层组合；蓝色角色直接使用完整原图。展示尺寸由页面样式控制，不修改原 SVG 内容。
