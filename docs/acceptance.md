# 页面验收清单

## 目录
- 结构与复用
- 响应式
- 内容与可访问性

## 结构与复用
- 页面专属文件归属正确，分区名称一致。
- 使用全站文字样式和已有组件；新增变体有说明。
- 没有将占位内容、模板或待确认设计值作为最终内容发布。

## 响应式
- 检查 320px、375px、768px、1024px、1440px 及其间连续缩放；这些是检查尺寸，不是强制断点。
- 无意外横向滚动，长标题、长链接和多语言内容不会破坏布局。
- 图片比例、内容顺序、导航折叠符合设计。

## 内容与可访问性
- 标题层级合理，每页有明确主标题和 main 区域。
- 图片有合理 alt；装饰图使用空 alt。
- 导航、按钮和链接可用键盘操作，焦点可见。
- 各背景版本下文字、链接和交互状态对比度合适。
- 检查真实链接、加载失败、字体回退及减少动画偏好。
