## 限制
本地 39MB 文件的网络读取很快，不能据此推断真实用户加载速度；线上需要 CDN / 压缩和设备实测。本轮未在实体 Safari / Windows / 低内存电脑上测峰值内存或 CPU。原始逐帧 Lottie 的潜在内存成本仍存在，默认选择小视频避免它。默认 VP9 WebM 已验证透明角落 alpha=0，草坪和天空为独立网页图层；MP4 后备含固定背景，仍有有损色差风险。未在实体 Safari 上验证 alpha 检测回退，不能把 Chromium 结果视为所有浏览器实测。两份素材最终是同步图层还是顺序片段仍待用户对照预览确认，当前默认同步叠加。手机素材尚未提供，因此不显示、不下载电脑版动画。
