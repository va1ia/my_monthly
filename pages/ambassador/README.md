## 页面与设计来源
入口 `ambassador.html`。按 [Figma Ambassador 区域](https://www.figma.com/design/xKlCUK40XPwLkxbY9JOWIZ/?node-id=17-68173) 的桌面 / 手机稿实现；标题、云朵、文件夹、图钉、图标、背景与人物均使用下载后的原 SVG。标题用隐藏 H1 提供文字名称，插画层为装饰。字体使用已集中注册的 BBH Sans Bogle 与 Graphik；棕色及页面字号为本页局部映射，不作为新增全站品牌规范。

复用 Menu bar / Footer 与订阅服务。设计已提供 Perks 人物结尾，因此此页显式 `preFooter:false`，不再追加通用花园。全站 Pre-footer 的 Ambassador 卡片进入本页，页面内部 Apply Here 继续跳转既有 Typeform。Instagram 使用用户指定 Reel，未添加跟踪参数。

## 互动与无障碍
- 桌面（≥768px）四朵装饰云在原有尺寸上缩为 0.6，手机保持原尺寸。独立眼睛按鼠标在整个视口中的位置线性映射、限幅移动，眼睛自身再逆时针旋转以与云朵方向接近；不依赖眼睛当前坐标计算，避免近处跳变和远处不动。四朵云共享额外向上的滚动位移（滚动距离的 16%），因此内容上行时云层更快上行；桌面 0.6 缩放下实际额外位移为 9.6%，四朵始终一致。≥768px 精细指针下，云身再叠加眼睛横向幅度 28% / 纵向幅度约 28% 的平滑鼠标位移；眼睛自身保留更大的独立位移。离开窗口后平滑复位。
- Marquee 为两组等长内容，平移一组长度后无缝循环；已移除暂停按钮、按钮事件和手动暂停状态，只有减少动态效果偏好停止循环。
- 文件夹恢复原稿比例：封面与后方纸张共用 1531×1408 比例，手机不再额外拉高画布；展开双页按 Figma 的 2954.43×1224.167 画布定位两块原 SVG 底板、左右独立旋转粉纸和两张白纸，保留中缝重叠与不对称外露。底板 height:auto，禁止矩形拉伸；手机右纸末尾按纸张边界定位，保证可完整读到。
- 手机 Perks 使用原稿两份独立 pattern；木框宽度 70.74%，手机纸张和字号按原稿比例缩放，蓝 / 绿人物分别为屏宽 27.81% / 28.77%，位置对应 Figma 手机稿。桌面背景继续使用原桌面图。
- Program 使用原生纵向滚动和 sticky 舞台，不拦截滚轮或触摸。先让封面落下，露出资格纸张，再将轨道左移展示右侧完整双页，末尾留阅读距离后解除固定。手机双页保持可读宽度，纵向滚动依次移过两张纸。上滑可逆向恢复。
- 已移除三个分段按钮及对应脚本、样式；继续使用原生滚动与 Space / PageDown / PageUp 浏览。回形针前段按原稿前后图层坐标上移，贴住纸张顶部，不进入标题区。Perks 纸张可键盘聚焦，绕顶部中央图钉轻微转动，图钉保持静止。
- 底部两个入口使用语义链接，在到达 Footer 前固定于视口底部；抵达 Footer 顶部的独立占位区域时切换为绝对定位，随页脚向上滚动。占位高度按按钮实际高度测量；body 不再添加页脚后的额外底部留白。手机安全区域保留，移动导航打开时隐藏。
- 绿色人物从 Figma 原整组导出为单个 `character-green.svg`，不再拆分拼接。
- `prefers-reduced-motion: reduce` 关闭眼神、视差、跑马灯和纸张旋转，文件夹所有文字改为正常文档流，不需要横向动画即可读取。偏好改变时重新测量。

## 文件归属
`page.js` 为结构；`styles/ambassador/index.css` 为样式；`scripts/ambassador/index.js` 为数据与互动入口；文案与链接在 `content/ambassador/page.json`；素材在 `assets/images/ambassador/{hero,program,perks}/`。共享色板与字体注册位于 foundations；本页特殊字体选择和字号在 styles/ambassador/index.css 中维护。
