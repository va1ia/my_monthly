## 字段
- csvUrl：MM Website Copy 的 Q&A: All 导出地址，固定 gid=1307779966；不是简略 Q&A: Preview 的 gid=0。
- refreshSeconds：可见页面的刷新间隔，当前 60 秒，共享读取器最低允许 30 秒。
- stopBefore：第一列中的停止标记，当前为 COMING SOON；该行与其后所有行均不显示，忽略标记大小写和多余空白。

## 更新规则
在表格的 Q / A 两列直接维护内容即可。网页启动时拉取，之后自动检查更新；仅显示 COMING SOON 之前问题和答案均非空的行，问题顺序跟随表格，删除行会从网页移除。问答不复制到 JSON。多段答案保持换行，所有内容作为纯文本显示。公开 CSV 读取权限需保留，用户表格本身未被本任务修改。
