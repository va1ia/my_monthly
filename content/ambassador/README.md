## 字段
`page.json`：`applyUrl` 为申请表，`instagramUrl` 为用户指定 Reel，`marquee` 为重复公告；`introTitle` / `intro` 为项目介绍；`eligibilityTitle` / `eligibility` 为申请资格；`learningTitle` / `learning` / `learningEnd` 为学习内容与结语；`perks` 包含标题、正文及图标 / 图钉素材名。

## 来源与维护
文字来自本次 Figma 对应节点；没有推断或添加奖励、报酬等承诺。申请链接沿用现有 Pre-footer Typeform，Instagram 为用户在对话中提供的链接。修改素材标识时须同步素材与结构，JSON 不添加注释。
