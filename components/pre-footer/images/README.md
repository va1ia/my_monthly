## 引用与维护
由上级 pre-footer.js 的相对 URL 引用。文件仅移动归类，SVG 路径和色值不改写；源动画放 source/，生成媒体放 media/，不混放在这里。替换同名插画后刷新页面即可；删除或改名时同步检查代码引用。App Store 徽章继续复用全站已有素材，不在此复制。
